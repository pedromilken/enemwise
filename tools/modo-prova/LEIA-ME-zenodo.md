# ENEM exam mode: LLM agents and simulated candidates sitting the ENEM 2009–2025

Data and code for the "exam mode" validation of the ENEM practice platform (knowledge tracing on a no-learning control case).
Generated on {{DATA}} from commit `{{COMMIT}}`.

*Resumo em português:* agentes de LLM (cinco modelos), candidatos simulados pela TRI do INEP e um agente aleatório fazem a
1ª etapa do ENEM de 2009 a 2025 com os cadernos reais e o tempo oficial; as análises comparam o acerto por posição, o KT
e o alinhamento com 11,3 bilhões de respostas reais dos microdados.

## Runs

{{RODADAS}}

20 candidates per edition × 17 editions (2009–2025) per source. Agents have no memory across items (`memoria: nenhuma`), answer keys
only between days, guessing disabled; items left when the virtual clock runs out become random guesses (`esgotado: chute`).
Sources: `ollama_*` local 8B models, `deepseek_deepseek-flash` (API), `aleatorio` (random answers), `nulo-tri` (candidates drawn from the
INEP 3PL, θ ~ N(0,1), no order effect), `nulo-tri-efeito` (same, −0.01 logit per position), `*persona*` (agents with a skill profile).

## Reproduce

Requirements: Python 3.10+ (`pip install -r` the packages in `ambiente.txt`, at least numpy, pandas, scipy, pyarrow, pymupdf, fonttools),
Node 20+, Ollama for local models. On Windows the wrapper `tools/modo-prova/rodar-prova.ps1` runs every step; the Python and Node
scripts run on any OS.

1. **Analyses only (from this record):** unzip `modo-prova-resultados.zip` and `modo-prova-dados.zip` into the repository root, then
   `python tools/modo-prova/analisar_prova.py <run folder>`, `python tools/modo-prova/kt_prova.py <run folder> [--so-resolvidas]`
   and `python tools/modo-prova/tabela1.py`.
2. **Exam texts:** `baixar-provas-enem.ps1` (official INEP PDFs) and `rodar-prova.ps1 -Etapa preparar -Microdados <folder with ITENS_PROVA_<year>.csv>`
   (text extraction + local vision model `qwen2.5vl:7b` for figures and formulas).
3. **Runs:** `rodar-prova.ps1 -Etapa completo -Rodada <name> -Memoria nenhuma -Cerebros "qwen3:8b,..." -Apis "deepseek:deepseek-flash,aleatorio"`
   (DeepSeek needs `DEEPSEEK_API_KEY`); `-Persona habilidades` for the persona condition; `-Etapa nulo` for the IRT nulls.
4. **Real accuracy:** `rodar-prova.ps1 -Etapa real -LongoConfig pipeline/v92.json`, with the long export of the confounders pipeline
   (v9.2, `results_v9_<year>_<area>/long.parquet`); the public microdata alone (`-Microdados`) cover CH, CN and MT.

Local LLMs sample with temperature 0.7 and a fixed seed per candidate (`semente: enem`); runs are resumable and deterministic up to the
nondeterminism of the inference backend, so re-runs reproduce the analyses' conclusions, not every answer.

## Main results (Table 1)

See `modo-prova-TABELA1.md`. In short: the IRT null with an injected position effect reproduces the candidates' within-item slopes, the plain null
shows none; agents' late-exam drop comes from timed-out items (on solved items every slope is within ±0.04 pp/position and the fitted
AFM rate is not significant); the 20 candidates of one model behave almost as one respondent (agreement up to 0.97); BKT reports a
learning transition of 0.30 on agents and PFA beats the item-only baseline on IRT candidates by absorbing ability.
